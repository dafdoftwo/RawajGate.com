# قسم السبا — جيم باور تايم (دمياط الجديدة)

حزمة تأهيل قسم السبا: تسعير وباقات، تشغيل الكول سنتر، مواصفات نظام المتابعة، وخطة الإعلانات.

| الملف | لمن | المحتوى |
|---|---|---|
| [`01-strategy.md`](./01-strategy.md) | المالك | تشخيص الأسعار الحالية، نظام الفترتين (سيدات/رجال) وأثره على السعة والذروة، هيكل التسعير الجديد (5 طبقات)، سلّم الحمّام (تركي/مغربي) وباقات العرسان كشريحة كاملة، الهامش، نموذج العائد، KPIs، خطة 90 يوم، مسح المنافسين |
| [`02-call-center-playbook.md`](./02-call-center-playbook.md) | موظفة الكول سنتر + الاستقبال | رحلة الليد خطوة بخطوة، سكريبتات واتساب مصرية، الاعتراضات، التقارير |
| [`03-lead-system-spec.md`](./03-lead-system-spec.md) | مطوّر نظام Firebase | Collections وحقولها، آلة حالات الليد، قواعد الأتمتة، حساب المؤشرات، الصلاحيات، الشيت المؤقت |
| [`04-ads-offers.md`](./04-ads-offers.md) | من يدير الإعلانات | توزيع الميزانية، الجماهير، الزوايا، UTM، الأهداف الرقمية، نص منشور الأسعار الجديد |
| [`spa-pricing-calculator.xlsx`](./spa-pricing-calculator.xlsx) | المالك | حاسبة حية: غيّر نسبة المعالج أو أي سعر فتتحدث هوامش الخدمات والباقات وسيناريوهات الحملة |

## ترتيب الاستخدام
1. اقرأ `01-strategy.md` واعتمد الأسعار (أو عدّلها في الحاسبة أولاً وراجع الهوامش).
2. املأ نموذج مسح المنافسين (القسم 9) قبل اعتماد الحمام المغربي وباقة العرسان.
3. سلّم `02` للموظفة وابدأ بالشيت المؤقت الموصوف في `03` القسم 7.
4. أطلق حملة اختبار واحدة وفق `04` القسم 1.
5. ابنِ نظام Firebase وفق `03` عندما تستقر العمليات (الأسبوع 4-6).

هذه الملفات مستقلة تماماً عن كود موقع الرواج ولا تؤثر على بنائه.
