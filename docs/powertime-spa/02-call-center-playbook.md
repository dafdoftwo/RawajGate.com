# دليل الكول سنتر — قسم السبا (باور تايم)

> هذا الدليل لموظفة الكول سنتر. الهدف: تحويل كل ليد إلى حجز مدفوع العربون، ثم إلى عميل متكرر.
> الأسعار الرسمية في `01-strategy.md` القسم 3. لا تُذكر أي أسعار غير المكتوبة هناك.

---

## 1. رحلة الليد (SOP) — من الرسالة الأولى إلى العميل الدائم

| المرحلة | التوقيت | الإجراء | الحالة في النظام |
|---|---|---|---|
| **1. الرد الأول** | خلال **5 دقائق** في ساعات العمل، خلال 60 دقيقة خارجها (رد تلقائي فوراً) | ترحيب + سؤال تأهيل واحد | `new` → `contacted` |
| **2. التأهيل** | نفس المحادثة | معرفة: الخدمة، رجالي/حريمي، الوقت المفضل، هل عضو جيم | `contacted` → `qualified` |
| **3. العرض** | نفس المحادثة | عرض واحد مناسب + موعدين محددين للاختيار (لا تسأل "إمتى تحب؟") | |
| **4. الحجز والعربون** | خلال ساعة من الموافقة | تثبيت الموعد + رقم إنستاباي/فودافون كاش + انتظار صورة التحويل | `qualified` → `booked` (بعد وصول العربون) |
| **5. التأكيد** | فور استلام العربون | رسالة تأكيد بالتفاصيل + الشروط + اللوكيشن | |
| **6. التذكير الأول** | قبل الموعد بـ 24 ساعة | رسالة + طلب تأكيد بـ "تمام" | |
| **7. التذكير الثاني** | قبل الموعد بـ 3 ساعات | رسالة قصيرة | |
| **8. الحضور** | يوم الموعد | الاستقبال يسجل الحضور، والمعالج يعرض ترقية "اليوم فقط" | `booked` → `showed` أو `no_show` |
| **9. ما بعد الجلسة** | بعد 24 ساعة | رسالة رضا + طلب تقييم جوجل | `showed` → `active` |
| **10. الترقية** | بعد 7 أيام | عرض الكورس/الاشتراك لمن لم يشترِ | `converted` عند الشراء |
| **11. إعادة الحجز** | حجامة: بعد 21 يوم، مساج: بعد 14 يوم، سبا: بعد 7 أيام | رسالة "ميعادك قرب" + موعدين | |
| **12. الاسترجاع** | بعد 45 يوم بلا زيارة | عرض عودة | `active` → `dormant` → `active` |
| **13. الإغلاق** | 3 محاولات بلا رد على 5 أيام، أو رفض صريح | تسجيل سبب الخسارة | → `lost` |

### قواعد الاتصال
- المكالمات من 10 صباحاً إلى 10 مساءً فقط. الواتساب في أي وقت للرد على العميل، أما المبادرة (تذكير/متابعة) فمن 10 ص إلى 9 م.
- محاولات المتابعة لليد الصامت: **3 محاولات على 5 أيام** (يوم 1 رسالة، يوم 3 مكالمة، يوم 5 رسالة أخيرة بعرض)، ثم إغلاق بسبب "لا رد".
- كل تواصل يُسجَّل في النظام بسطر واحد (التاريخ، القناة، الخلاصة، الخطوة التالية وموعدها).
- العميل الذي يقول "هفكر" لا يُغلق؛ يُحدد له متابعة بعد 48 ساعة.
- ممنوع إرسال قائمة الأسعار كاملة كصورة كرد أول. الرد الأول سؤال، وليس قائمة.
- **لا يُحجز عميل أبداً في فترة الجنس الآخر.** أول شيء تتأكدين منه قبل عرض أي موعد: جنس العميل ← فترته.

### مواعيد الفترتين (تُحفظ عن ظهر قلب وتُلصق بجوار الشاشة)

| اليوم | السيدات | الرجال |
|---|---|---|
| السبت / الاثنين / الأربعاء | 8 ص – 4 م | 4 م – 1 ص |
| الأحد / الثلاثاء / الخميس | 3 م – 7 م | 8 ص – 3 م ثم 7 م – 1 ص |
| الجمعة | — | 3 م – 10:30 م |

قواعد التوجيه داخل الفترة:
- **سيدات:** عروض التعارف والسبا المفرد → السبت/الاثنين/الأربعاء 8 – 12 ظهراً. الباقات والمساج → أي وقت. الحمام الملكي وباقات العرسان → السبت/الاثنين/الأربعاء 8 ص – 1 م فقط (يُفضَّل الأربعاء للعروسة).
- **رجال:** عروض التعارف → الأحد/الثلاثاء/الخميس 8 ص – 3 م أو أي يوم بعد 11 م. الذروة (6 – 11 م) للسعر الكامل.
- فترة السيدات 3 – 7 م قصيرة ومزدحمة: لا تُعرض فيها عروض تعارف؛ وجّهي طالبات العرض إلى الصباح.

## 2. السكريبتات (مصري بسيط، واتساب)

> استبدلي {الاسم} و{الموعد} و{العرض} بالبيانات الفعلية. الإيموجي واحد أو اثنان كحد أقصى.

### 2.1 الرد الأول — ليد جاي من إعلان
```
أهلاً بيك في باور تايم سبا 🌿
أنا {اسم الموظفة} من فريق الحجز.
عشان أرشّحلك الأنسب: حضرتك مهتم بـ (السبا / المساج / الحجامة)؟ ورجالي ولا حريمي؟
```

### 2.2 الرد الأول — رسالة بدون تحديد ("بكام؟" / "عايز أعرف الأسعار")
```
أهلاً بيك 🌿 أكيد هبعتلك التفاصيل.
بس عشان ماأبعتلكش حاجة مش هتفيدك: أنت مهتم أكتر بالاسترخاء (سبا ومساج) ولا بالعلاج (حجامة)؟ ورجالي ولا حريمي؟
```
> بعد الرد: أرسلي **عرضاً واحداً** فقط مناسباً لإجابته، مع موعدين.

### 2.3 عرض + موعدين (نموذج)
```
تمام يا {الاسم} 👌
الأنسب ليك عرض "{العرض}": {المحتوى} بـ {السعر} ج بدل {القيمة} ج (عرض أول زيارة).
عندنا متاح: {الاتنين 3 العصر} أو {الأربعاء 4 العصر} — أيهم أنسب؟
```

### 2.3b الرد على "إمتى الحريمي؟" / "إمتى الرجالي؟" (إجابة قاطعة، بلا تردد)
```
مواعيد الحريمي: السبت والاتنين والأربع من 8 الصبح لـ 4 العصر، والحد والتلات والخميس من 3 لـ 7 المغرب. مختصة حريمي بالكامل 🌿
أنسب لك الصبح ولا العصر؟
```
```
مواعيد الرجالي: السبت والاتنين والأربع من 4 العصر لـ 1 بالليل، والحد والتلات والخميس من 8 الصبح لـ 3 ومن 7 لـ 1، والجمعة من 3 لـ 10:30.
أنسب لك الصبح ولا بالليل؟
```

### 2.4 تثبيت الحجز والعربون
```
حجزتلك {الموعد} مع {المختص/المختصة}.
عشان أثبّت الميعاد باسمك نهائياً، عربون 100 ج على:
• إنستاباي: {الرقم}
• فودافون كاش: {الرقم}
العربون بيتخصم من سعر الجلسة، وابعتلي صورة التحويل هنا وأبعتلك التأكيد فوراً 🙏
```
> لو مر ساعة بدون تحويل: رسالة لطيفة "الميعاد لسه محجوز باسمك لحد {الساعة}، بعد كده هيتفتح لغيرك".

### 2.5 رسالة التأكيد (بعد العربون)
```
تم التأكيد ✅
{الاسم} — {الخدمة} — {اليوم والتاريخ والساعة} — {المختص/المختصة}
المتبقي عند الحضور: {السعر − 100} ج
اللوكيشن: {رابط خرائط جوجل}
ملاحظات: تعال قبل الميعاد بـ 10 دقايق. تغيير الميعاد مجاني قبلها بـ 12 ساعة.
{للحجامة: يفضّل صيام 3 ساعات قبل الجلسة وشرب مياه كويس.}
```

### 2.6 التذكير قبل 24 ساعة
```
تذكير بميعادك بكرة {الساعة} في باور تايم سبا 🌿
لو كل حاجة تمام ابعتلي "تمام"، ولو محتاج تغيير قولي دلوقتي عشان أظبطهولك.
```

### 2.7 التذكير قبل 3 ساعات
```
مستنينك النهاردة {الساعة} 👋 {المختص/المختصة} جاهز/ة. اللوكيشن: {الرابط}
```

### 2.8 الغياب بدون إخبار
```
افتقدناك النهاردة يا {الاسم}. أكيد حصل ظرف.
أقدر أنقلك لميعاد تاني الأسبوع ده ونحتفظلك بالعربون كاستثناء المرة دي؟ متاح {موعد 1} أو {موعد 2}.
```

### 2.9 ما بعد الجلسة (بعد 24 ساعة)
```
إزيك يا {الاسم}، حاسس بفرق بعد جلسة إمبارح؟ 🌿
لو التجربة عجبتك، تقييمك على جوجل هيفرق معانا جداً (دقيقة واحدة): {رابط التقييم}
ولو في أي ملاحظة، قولهالي هنا وأنا هوصّلها بنفسي.
```

### 2.10 الترقية (بعد 7 أيام)
```
{الاسم}، عشان النتيجة تكمل: {المختص} نصح إن {الحجامة تتكرر كل 3-4 أسابيع / المساج كل أسبوعين}.
كورس {3 حجامات + 3 سبا كاملة} بـ 1499 بدل 2850، وتحجز مواعيدك من دلوقتي.
تحب أحجزلك الجلسة الجاية وأثبّتلك السعر؟
```

### 2.11 إعادة الحجز ("ميعادك قرب")
```
{الاسم}، عدى {3 أسابيع} على جلستك الأخيرة، ده الوقت المناسب للجلسة الجاية 👌
متاح {موعد 1} أو {موعد 2} مع {المختص}؟
```

### 2.12 الاسترجاع (بعد 45 يوم)
```
وحشتنا يا {الاسم} 🌿
رجّعنالك سعر أول زيارة: {سبا كاملة 199 / جلستك المفضلة بخصم 15%} صالح لغاية {تاريخ بعد 7 أيام}.
أحجزلك؟
```

### 2.14 العروسة — الرد الأول (ليد من حملة العرسان أو من شريك)
```
ألف مبروك يا {الاسم} 🤍 فرحك إمتى إن شاء الله؟
عشان أرتّبلك الأنسب: عايزة جلسة واحدة قبل الفرح بيومين، ولا برنامج 3 أسابيع يظهر على بشرتك فعلاً في يوم الفرح؟
```
> بعد الرد: لو الفرح بعد أكثر من 3 أسابيع → اعرضي **برنامج العروسة 3,499** أولاً. لو أقل → **باقة العروسة 2,199**. وفي الحالتين اسألي: "وفي صحباتك هيجوا معاكي؟" (يوم العروسة وصحباتها 3,999).

### 2.15 العروسة — عرض الباقة والحجز
```
باقة العروسة: حمام مغربي ملكي (صابون بلدي + كيس + غسول) + مساج خفيف تنشيطي + جلستين سبا كاملة (واحدة قبلها بأسبوع وواحدة يوم الباقة) بـ 2,199 بدل 2,899.
بنحجزها الصبح في يوم السبت أو الاتنين أو الأربع عشان الجلسة بتاخد 3 ساعات براحة، والأربع أنسب لو الفرح الخميس.
العربون 300 ج بيتخصم من السعر. أحجزلك {الأربع الجاية 9 الصبح}؟
```

### 2.16 العريس والعرسان معاً (يُعرض على كل عروسة بعد الحجز)
```
وللعريس عندنا باقة في فترة الرجالي: حمام تركي + مساج كلي + سبا كاملة بـ 1,599.
ولو حجزتوا الاتنين مع بعض "باقة العرسان" بـ 3,299 بدل 3,798، وممكن حد من الأهل يهديهالكم 🎁
أبعتلك التفاصيل تشاركيها معاه؟
```

### 2.17 هدية العرسان (لمن يتصل ليهدي)
```
هدية العرسان عندنا قسيمة بقيمة 1,000 أو 2,000 أو 3,299 (باقة العرسان كاملة)، بتتصرف على أي باقة عرسان، صالحة 6 شهور، وبنبعتها بتصميم باسم المُهدي.
تحب القيمة كام؟ والدفع إنستاباي أو فودافون كاش وأبعتلك القسيمة خلال ساعة.
```

### 2.18 عضو الجيم (بيع داخلي — واتساب لقاعدة الأعضاء)
```
لأعضاء باور تايم بس 💪
باقة "ريكفري": 4 جلسات سبا كاملة + مساج كلي كل شهر بـ 899 ج (بدل 2100).
الاستشفاء بعد التمرين = نتيجة أسرع وإصابات أقل. تحب تفعّلها مع اشتراكك؟
```

## 3. الاعتراضات وكيف تُعالَج

| الاعتراض | الرد |
|---|---|
| **"غالي"** | "فاهمك. الجلسة شاملة {السبا الكاملة + التعقيم الكامل + مختص متخصص}. ولو عايز تجرب الأول، عرض أول زيارة {199/299/349} وبعدها تقرر براحتك." لا تُخفّض السعر أبداً؛ انزل درجة في العرض. |
| **"بعيد عني"** | "جلسة الاسترخاء نفسها ساعتين، يعني مشوار يستاهل. وفي باركينج. تحب ميعاد آخر اليوم عشان ما تتعطلش؟" |
| **"في مختصة حريمي؟"** | "أيوه، عندنا مختصة حريمي، وفترة الحريمي من {الساعة} لـ {الساعة} {الأيام}." (إجابة مباشرة وقاطعة، لا تتردد). |
| **"الحجامة آمنة؟ بتوجع؟"** | "الحجامة عندنا بأدوات معقمة تُستخدم مرة واحدة، والمختص خبرة {س} سنين. الإحساس شد بسيط مش وجع، ومعظم الناس بتحس براحة من نفس اليوم. لو عندك حالة صحية معينة قولي عشان أستشير المختص قبل الحجز." |
| **"هفكر وأرد عليك"** | "براحتك طبعاً. بس عشان الميعاد ده متاح دلوقتي، أحجزهولك مبدئياً لحد بكرة {الساعة} من غير عربون؟" ثم متابعة بعد 48 ساعة. |
| **"ليه عربون؟"** | "عشان المختص بيحجز وقته ليك بالكامل وما يقبلش حد تاني في ميعادك. والعربون بيتخصم من السعر، مش زيادة." |
| **"ممكن أجي من غير حجز؟"** | "ممكن، بس مش هضمنلك المختص أو الوقت. بالحجز بأضمنلك الجلسة كاملة في ميعادك بالظبط." |
| **"مواعيد الحريمي مش مناسبة لي" (شغل صباحي)** | "عندنا الحد والتلات والخميس من 3 لـ 7، وده بيناسب اللي بيخلّص شغل بدري. ولو الصبح صعب، السبت 8 الصبح قبل الشغل وبتخلّصي في ساعة ونص." لا تعِدي بمواعيد خارج الفترة أبداً. |
| **العروسة: "مش فاضية قبل الفرح"** | "عشان كده بنحجز الصبح بدري ونخلّص في 3 ساعات، وبنبعتلك تذكير قبلها بيوم. ولو حابة، خلّي جلسة السبا الأولى الأسبوع اللي قبله وهي 75 دقيقة بس." |
| **"الفرق بين المغربي والتركي إيه؟"** | "المغربي تنظيف عميق للبشرة بصابون بلدي وكيس وغسول، نتيجته نعومة وتوحيد لون. التركي تقشير بالكيس ومساج بالرغوة جوه البخار، نتيجته استرخاء عضلي. للعروسة بنرشّح المغربي الملكي، وللعريس أو بعد التمرين التركي." |

## 4. الردود التلقائية (واتساب بيزنس)

**رسالة الترحيب (خارج ساعات العمل):**
```
أهلاً بيك في باور تايم سبا 🌿 وصلتنا رسالتك وهنرد عليك أول ما نبدأ الساعة 10 صباحاً.
عشان نسرّع: اكتبلنا الخدمة اللي مهتم بيها (سبا / مساج / حجامة) ورجالي ولا حريمي.
```

**الردود السريعة المحفوظة (Quick Replies):** `/اهلا` `/مواعيد-حريمي` `/مواعيد-رجالي` `/عرض-سبا` `/عرض-مساج` `/عرض-حجامة` `/حمام-مغربي-تركي` `/عروسة` `/عريس` `/هدية-عرسان` `/عربون` `/تأكيد` `/تذكير24` `/تذكير3` `/لوكيشن` `/تقييم` `/كورس` `/ريكفري`

## 5. ترقية "اليوم فقط" (للاستقبال والمعالج)

في نهاية كل جلسة أولى، الاستقبال يقول جملة واحدة:
> "لو حجزت الكورس/الباقة دلوقتي قبل ما تمشي، عليها خصم إضافي 100 ج النهاردة بس."

ويُسجَّل الرد (اشترى / رفض / يفكر) في النظام لأن الكول سنتر ستتابع بناءً عليه.

## 6. التقارير

### 6.1 تقرير نهاية اليوم (يُرسل للمالك على واتساب الساعة 10 م)
```
تقرير السبا — {التاريخ}
ليدز جديدة: {ن} (فيسبوك {ن} / إنستجرام {ن} / تيك توك {ن} / واتساب {ن} / جيم {ن})
تم الرد على: {ن}   متوسط سرعة الرد: {د} دقيقة
حجوزات جديدة: {ن}   عربون مستلم: {ن}
حضور النهاردة: {ن} من {ن} حجز   غياب: {ن}
ترقيات (باقة/كورس): {ن} بقيمة {ج}
إيراد اليوم: {ج}
متابعات بكرة: {ن}
ملاحظة/مشكلة: {نص}
```

### 6.2 مراجعة أسبوعية (المالك + الموظفة، 20 دقيقة)
1. الأرقام مقابل الأهداف (القسم 7 في الاستراتيجية).
2. أفضل قناة وأفضل عرض هذا الأسبوع.
3. أكثر 3 أسباب خسارة ليدز، وماذا نغير في السكريبت.
4. مواعيد الأسبوع القادم: أي أيام فارغة تحتاج دفعة عروض.
